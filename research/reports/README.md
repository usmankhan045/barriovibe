# Agent reports

Verbatim output of the research agents, kept because the reports carry their own
caveats and those caveats matter as much as the findings.

Every one of the first four agents was **blocked from reddit.com**, and each said
so rather than substituting invented data. None had a keyword tool, so their
volume tiers are reasoned estimates, not measurements. Read the limitation
sections before treating any number here as fact; the ones that have since been
verified against primary sources are in ../findings.jsonl with status `verified`.
